# בדיקות קבלה — Telegram (פיילוט)

## א. סקריפט אוטומטי
```
npm run acceptance:telegram -- --local          # מקומי: Telegram מדומה, AI כבוי, אחסון בזיכרון; חוסם כל יציאה לרשת
npm run acceptance:telegram -- --url https://<service>.onrender.com   # שרת פרוס: HTTP בלבד (קריאה בלבד)
```
- `--local` בודק: `/health`, `/api/privacy/status`, חסימת web chat בלי הסכמה (403 CONSENT_REQUIRED), ולכל שפה (he/en/th): הודעת הסכמה בהודעה ראשונה, הודעת פרטיות, accept, "המידע שלי", קוד מחיקה, withdraw → שוב הודעת הסכמה, accept + מחיקה עם קוד. כרגע 28/28 עוברים; רץ גם ב-CI (`test/acceptance-telegram-script.test.js`).
- `--url` לא שולח הודעות Telegram ולא כותב נתונים.
