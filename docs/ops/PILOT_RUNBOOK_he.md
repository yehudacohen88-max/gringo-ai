# Gringo — ספר הפעלה לפיילוט (ללא סודות)

## 1. הפעלה
- תהליך יחיד בלבד: מופע אחד, בלי cluster ובלי autoscaling (מטמון Sheets של 45 שניות, קודי מחיקה ומגבלות קצב נשמרים בזיכרון התהליך).
- `NODE_ENV=production`. השרת יסרב לעלות אם PrivacyConsents/PrivacyAudit לא נגישים לקריאה וכתיבה.
- סודות רק במנהל הסודות של ספק האירוח. `.env.example` הוא תבנית בלבד.
- `TRUST_PROXY_HOPS` נקבע רק אחרי בחירת ספק. LINE נשאר כבוי עד אימות redelivery.

## 2. בדיקות אחרי עלייה
1. `GET /health` מחזיר 200.
2. בלוג: `Durable privacy storage verified` ו-`Pilot mode: run a single Gringo process only`.
3. `GET /api/admin/ai-usage` (עם מפתח אדמין) מציג `enabled: true` והמגבלות הצפויות.

## 3. עלויות AI
- מתג חירום: `AI_ENABLED=false` ואתחול. המשתמשים מקבלים תשובות מבסיס הידע ותשובת fallback ידידותית.
- מגבלות יומיות: `AI_DAILY_USER_LIMIT`, `AI_DAILY_GLOBAL_LIMIT`, `AI_DAILY_TOKEN_LIMIT` (ספירה לפי יום UTC, מתאפסת באתחול).
- חובה בנוסף: תקרת תקציב חודשית קשיחה בלוח הבקרה של OpenAI (פעולה של יהודה).
- לוג `[ai-budget] AI calls blocked for today` = הגעה לתקרה גלובלית.

## 4. תקלה ב-Google Sheets
- סימפטום: משתמשים מקבלים "השירות לא זמין"; המערכת חוסמת עיבוד (fail-closed). אין לעקוף.
- בדיקה: הרשאות חשבון השירות, מכסות API של Google, סטטוס Google Workspace.
- אחרי שחזור: לאתחל את התהליך ולוודא את שורת האימות בלוג.

## 5. בקשת מחיקה שנתקעה (deletion_pending)
1. המשתמש חסום לעיבוד עד השלמה.
2. ניסיון חוזר: `POST /api/admin/privacy/retry-deletions` עם מפתח אדמין, או הודעה הבאה של המשתמש.
3. לתעד ביומן ידני: תאריך, מזהה פנימי (לא שם/טלפון), תוצאה.
4. מה המחיקה לא מכסה: היסטוריית גרסאות של Google, עותקים אצל OpenAI ואצל ספקי הערוצים, לוגים של ספק האירוח, גיליונות ניהול ודוחות יומיים. לא להבטיח למשתמש מחיקה מלאה.

## 6. גיבויים
- גיבוי שבועי ידני: File → Make a copy של הגיליון לתיקייה מוגבלת (רק יהודה). הגיבוי מכיל מידע אישי, ולכן מחיקה של משתמש צריכה להיות מתועדת גם מול גיבויים (מדיניות שמירה — אישור משפטי).
- אסור לייצא גיבויים למחשבים אישיים או לשתף אותם.

## 7. אירוע אבטחה
1. לעצור: `AI_ENABLED=false`, `TELEGRAM_BOT_ENABLED=false`, `WHATSAPP_ENABLED=false`, אתחול.
2. להחליף סודות שנחשפו (יהודה בלבד): ADMIN_API_KEY, WEB_SESSION_SECRET, מפתח OpenAI, טוקן Telegram, סודות WhatsApp, מפתח חשבון השירות של Google.
3. לבדוק שיתופי הגיליון והסרת גישות.
4. לתעד ציר זמן. חובת דיווח לרשות להגנת הפרטיות — לפי ייעוץ משפטי.
